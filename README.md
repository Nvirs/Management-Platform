# Cloud-Native Event Management Platform

A system where users can create events, register for them, and receive notifications.

## Architecture

```
Gateway
├── Auth Service (Spring Boot)
├── Event Service (Spring Boot)
├── Registration Service (FastAPI)
├── Notification Service (Node.js)
RabbitMQ
PostgreSQL
Redis
```

## Tech stack

- Spring Boot
- FastAPI
- Node.js
- PostgreSQL
- Redis
- RabbitMQ
- Docker
- Kubernetes
- Helm
- GitHub Actions
- AWS EKS
- Prometheus
- Grafana
- OpenTelemetry
